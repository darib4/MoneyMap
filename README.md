# MoneyMap

MoneyMap is a personal finance management web application built with HTML, CSS, and JavaScript.

The application helps users track their income and expenses, manage budgets, monitor financial goals, and view simple financial statistics.

## Technologies

- HTML5
- CSS3
- JavaScript
- Supabase

## Planned Functionality
The project is currently under development.
Planned features include:
- Authentication with Supabase
- Transaction management
- Monthly budget tracking
- Savings goals
- Expense analytics
- Interactive charts
  
## Purpose
This project was created to practice front-end development, JavaScript logic, working with APIs and databases, and building a complete responsive web application.
